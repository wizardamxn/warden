# Study screens

Flashcards and quizzes made from notes. Testing yourself helps memory far more than rereading, so this is where learning actually sticks.

- Flashcards: soft card flip. Next slides the card aside and the next lifts off the deck; Revise's pile drops onto the desk when it opens.
- Quizzes: on submit, question by question, the highlighter sweeps the right answer and the red pen stamps the mark; the score counts up (see docs/DESIGN.md).
- One small celebration at the end of a quiz, once. Skipped when the device asks for less motion.
