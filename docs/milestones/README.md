# Milestones

One folder per milestone (M01-name, M02-name, ...), each with PLAN.md before building and SUMMARY.md after.

- [M01-first-note](M01-first-note/PLAN.md): paste a NEET lecture link in a terminal, get a note file (captions + Gemini). Done on one lecture, see [SUMMARY.md](M01-first-note/SUMMARY.md).
- [M02-neet-study](M02-neet-study/PLAN.md): NEET notes, flashcards and quiz as three separate saved steps. Done on one lecture, see [SUMMARY.md](M02-neet-study/SUMMARY.md).
- [M03-web-notes](M03-web-notes/PLAN.md): the website, with the real YouTube player and synced notes. Done for local testing, see [SUMMARY.md](M03-web-notes/SUMMARY.md).
- [M04-backend](M04-backend/PLAN.md): the Go API, job tables and always-on worker, with a logger. Done locally, see [SUMMARY.md](M04-backend/SUMMARY.md).
- [M05-web-api](M05-web-api/PLAN.md): the website on the real API, with real progress. Done locally, see [SUMMARY.md](M05-web-api/SUMMARY.md).
- [M06-study-screens](M06-study-screens/PLAN.md): flashcards and the OMR answer sheet. Built, not tested, see [SUMMARY.md](M06-study-screens/SUMMARY.md).
- [M07-accounts-revise-templates](M07-accounts-revise-templates/PLAN.md): accounts, limits, library, Revise and templates in the Go backend. Done, see [SUMMARY.md](M07-accounts-revise-templates/SUMMARY.md).
- [M08-accounts-revise-web](M08-accounts-revise-web/PLAN.md): the website side of accounts, library, Revise and templates. Done, see [SUMMARY.md](M08-accounts-revise-web/SUMMARY.md).
