# CLAUDE.md

Rules for Claude when working in this repo.

## How to work with me

- Don't turn your own ideas into "the plan". Anything I haven't chosen goes under "your call", with your recommendation marked as one option.
- No code until I say "build it".
- Never git commit unless I ask.
- Explain in chat, in plain language, short bullets. No artifacts unless I ask.

## Where things are written down

- Starting plan (cohort, MVP scope, build order): [docs/PLAN.md](docs/PLAN.md).
- Decisions, v1 features, what's still open: [README.md](README.md).
- Website rules (theme, layout, video player, motion): [apps/web/ARCHITECTURE.md](apps/web/ARCHITECTURE.md).
- Design guide (study + visual research, and the rules every screen follows): [docs/DESIGN.md](docs/DESIGN.md).

## Before any UI work

- Read [docs/DESIGN.md](docs/DESIGN.md) first, every time: website code, mockups, artifacts. Follow its rules; don't fall back to default "AI-looking" UI.
- Run its slop test before showing anything: if someone would guess "AI made this", redo it.
